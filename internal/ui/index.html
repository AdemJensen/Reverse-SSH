        关于 Reverse SSH

        Reverse SSH 是一款面向 macOS 和 Windows 的图形化 SSH 反向 TCP 转发工具。借助一台允许远程 TCP 转发的公网 SSH 服务器，本机没有公网 IP 也可以对外提供服务。

        一条 SSH 连接可转发多个端口。应用支持后台运行，也可在登录系统时自动启动并连接已保存的隧道。
